# Validation

- 310 unique question IDs and prompts; exactly five distinct choices per question.
- All questions include a B13 course PDF printed-page citation and an external anatomy reference.
- Six regions, four question types, and three learning priorities checked.
- Browser checks: 20-question session scoring, locked answers, ten-question missed-answer review, all 72 filter combinations, PDF citation dialog, and external links.
- Desktop and 390-pixel mobile layouts inspected; no horizontal overflow or JavaScript page errors.
- External links checked for availability; a university-login-only reference was replaced with a public University of Washington reference.
- Native WebMCP validation was unavailable in the test browser. Optional tools are feature-detected and do not affect normal quiz use.
